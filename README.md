# نظام مسيرات الرواتب و مكافئات العاملين في مدارس التعليم المستمر - إدارة التعليم بنجران

نظام ويب مستقل لإدارة مسيرات الرواتب للمدارس، مبني على Next.js وSupabase ومجهز للنشر على Vercel.

## المتطلبات
- Supabase project مستقل.
- متغيرات البيئة: `NEXT_PUBLIC_SUPABASE_URL` و `NEXT_PUBLIC_SUPABASE_ANON_KEY`.

## الحسابات
يستخدم النظام Supabase Auth. اسم المستخدم المدرسي يحول داخليًا إلى صيغة بريد اصطناعية `username@ceedu.local` دون تخزين كلمات المرور في قاعدة البيانات.
